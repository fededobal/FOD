# Fundamentos de Organización de Datos

Este repositorio contiene material relacionado con la materia "Fundamentos de Organización de Datos", incluyendo parciales y prácticas.

## Contenido

* **[Parciales](Parciales/)**: Colección de parciales y exámenes de la materia.
* **[Prácticas](Prácticas/)**: Directorio que contiene las diferentes prácticas de la materia.
    * **[Práctica 1 - Archivos](Prácticas/Práctica%201%20-%20Archivos/)**: Práctica enfocada en el manejo de archivos.
    * **[Práctica 2 - Archivos](Prácticas/Práctica%202%20-%20Archivos/)**: Continuación de la práctica de archivos.
    * **[Práctica 3 - Bajas](Prácticas/Práctica%203%20-%20Bajas/)**: Práctica relacionada con operaciones de baja de datos.
    * **[Práctica 4 - Árboles B y B+](Prácticas/Práctica%204%20-%20Árboles%20B%20y%20B+/)**: Práctica sobre la implementación y uso de árboles B y B+.
